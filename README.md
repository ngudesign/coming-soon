# Lisa Nguyen — Coming soon

A single, centered landing page with the name logo and "Portfolio coming soon",
shown while the full portfolio is in progress.

Everything lives in `index.html` (no build step). Colors and fonts match the
portfolio: Gloock for the name, Literata italic for the tagline, Oxblood Ink accent.

Preview locally:

```bash
python3 -m http.server 4330
```

Then open http://localhost:4330.
